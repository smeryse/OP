Контрольные вопросы:
Вопрос 1: Назовите четыре файла, в которых содержится информация о пользователях и группах?
Ответ: Информация о пользователях и группах в Linux хранится в следующих файлах: /etc/passwd – база пользователей, /etc/shadow – база паролей пользователей, /etc/group – база групп, /etc/gshadow – база паролей групп. В файле /etc/passwd содержатся основные атрибуты учётных записей, включая UID, GID, домашний каталог и оболочку. В /etc/shadow хранятся хеши паролей и параметры их старения. /etc/group содержит информацию о группах и их участниках, а /etc/gshadow – пароли групп и данные об администраторах групп.
Вопрос 2: Как называется файл бекапа для /etc/shadow?
Ответ: Резервная копия файла /etc/shadow называется /etc/shadow– (с дефисом в конце). Этот файл создаётся автоматически утилитами управления пользователями при внесении изменений и содержит предыдущую версию данных. Аналогичные резервные копии существуют для /etc/passwd–, /etc/group– и /etc/gshadow–.
Вопрос 3: Что означает «x» в поле пароля в файле /etc/passwd?
Ответ: Символ «x» во втором поле файла /etc/passwd означает, что для данного пользователя установлен пароль, и его хеш хранится в отдельном файле /etc/shadow. Это мера безопасности, поскольку /etc/passwd доступен для чтения всем пользователям, а /etc/shadow защищён от чтения обычными пользователями. Если в этом поле стоит «!», это указывает на то, что пароль не задан и интерактивный вход запрещён.
Вопрос 4: В каком файле хранятся настройки диапазонов UID, GID?
Ответ: Настройки диапазонов UID и GID для системных и обычных пользователей хранятся в файле /etc/login.defs. В этом файле определяются параметры UID_MIN, UID_MAX, GID_MIN, GID_MAX, а также диапазоны для системных учётных записей (например, SYS_UID_MIN, SYS_UID_MAX). Эти значения используются утилитами useradd и groupadd при автоматическом назначении идентификаторов. Также аналогичные параметры могут быть заданы в /etc/adduser.conf для скрипта adduser.
Вопрос 5: Что делает команда useradd -D?
Ответ: Команда useradd -D выводит текущие значения по умолчанию, используемые при создании новых пользователей. Эти параметры берутся из файла /etc/default/useradd. Вывод включает: GROUP (группа по умолчанию), HOME (базовый каталог для домашних папок), INACTIVE (период неактивности после истечения пароля), EXPIRE (дата истечения учётной записи), SHELL (оболочка по умолчанию), SKEL (каталог с шаблонами), CREATE_MAIL_SPOOL (флаг создания почтового ящика). С опциями можно также изменять эти значения, например, useradd -D -s /bin/bash установит bash как оболочку по умолчанию.
Вопрос 6: Какой UID присвоится первому созданному пользователю в системе?
Ответ: Первому созданному обычному пользователю в системе, как правило, присваивается UID 1000. Это значение определяется настройками в /etc/login.defs, где параметр UID_MIN обычно равен 1000. Однако в некоторых дистрибутивах диапазон может начинаться с 1000 или 500 (в старых системах). В Astra Linux, согласно практике, UID 1000 отдаётся первому пользователю, созданному при установке, а следующим присваиваются последовательные номера, если не указано иное. Если система создаёт системные учётные записи, они используют UID меньше 1000.
Вопрос 7: Какие две команды могут быть использованы для блокировки и разблокировки пользователя?
Ответ: Для блокировки и разблокировки пользователя можно использовать команды usermod и passwd. Блокировка: usermod -L <имя> или passwd -l <имя>. Разблокировка: usermod -U <имя> или passwd -u <имя>. Команда usermod также позволяет управлять сроком действия учётной записи (--expiredate), а passwd может использоваться для принудительной смены пароля при следующем входе (passwd -e). При блокировке в файл /etc/shadow перед хешем пароля добавляется символ «!», что делает аутентификацию по паролю невозможной.
Вопрос 8: Как заставить пользователя iivanov принудительно сменить свой пароль при следующем входе?
Ответ: Чтобы заставить пользователя iivanov сменить пароль при следующем входе, необходимо установить дату последнего изменения пароля в прошлое, например, с помощью команды sudo chage -d 0 iivanov. Это обнуляет счётчик дней с последней смены, и при следующей аутентификации система потребует установить новый пароль. Альтернативно можно использовать команду sudo passwd -e iivanov, которая также помечает пароль как истекший. После успешной смены пароля дата последнего изменения обновится.
Вопрос 9: Что делает команда faillog -u iivanov -r?
Ответ: Команда faillog используется для просмотра и сброса счётчиков неудачных попыток входа в систему, которые хранятся в файле /var/log/faillog. Конкретно faillog -u iivanov -r выполняет сброс (reset) счётчика неудачных попыток для указанного пользователя iivanov. Это может потребоваться для разблокировки учётной записи, если она была временно заблокирована из-за превышения лимита неудачных входов (хотя в современных системах чаще используется pam_tally2 или pam_faillock). В старых системах faillog управлял данными о блокировках.
