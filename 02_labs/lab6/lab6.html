Контрольные вопросы:
Вопрос 1: Какой командой можно посмотреть информацию о типе команды?
Ответ: Для просмотра информации о типе команды используется команда 'type <имя_команды>'. Она показывает, является ли команда встроенной в оболочку, алиасом, функцией или внешним исполняемым файлом.
Вопрос 2: Какая нотация используется для глобальных переменных?
Ответ: В Bash глобальные переменные (переменные окружения) обычно записываются заглавными буквами, например PATH, HOME, USER. Это соглашение об именовании, а не требование языка.
Вопрос 3: Какие кавычки позволяют подставить значение переменной?
Ответ: Двойные кавычки позволяют подставлять значения переменных. При использовании двойных кавычек символ $ интерпретируется и происходит подстановка значения переменной.
Вопрос 4: Какие кавычки экранируют специальный символ доллара $, не позволяя подставлять значения переменных?
Ответ: Одинарные кавычки (апострофы) экранируют все специальные символы, включая $. Внутри одинарных кавычек подстановка переменных не выполняется, текст передается буквально.
Вопрос 5: Какие конструкции языка позволяют повторить блок кода несколько раз в зависимости от условия?
Ответ: Для повторения блока кода используются циклы: for (когда известно количество итераций), while (пока условие истинно), until (пока условие ложно).
Вопрос 6: Какой конструкцией языка можно выполнить ветвление кода?
Ответ: Ветвление кода выполняется конструкцией if/then/elif/else/fi. Также можно использовать case для множественного выбора.
Вопрос 7: Как в языке Bash можно получить значение позиционных переменных?
Ответ: Позиционные переменные доступны через $1, $2, $3 и т.д. (аргументы командной строки). $0 — имя скрипта, $@ — все аргументы, $# — количество аргументов.
Вопрос 8: Какой командой можно очистить переменную?
Ответ: Для очистки переменной используется команда unset <имя_переменной>. Также можно присвоить пустое значение: variable="".
Вопрос 9: С помощью какой специальной переменной можно получить значения всех аргументов?
Ответ: Все аргументы можно получить через $@ (каждый аргумент как отдельное слово) или $* (все аргументы как одно слово).
